## Сборка

Основной документ — `report/main.tex`. Для локальной сборки нужен TeX Live с пакетами кириллицы (включая LH/CM-Super); пример:

```sh
cd report
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```
